Loaded by Claude Code on every invocation in this project.

## Skills (project-local)

The `.claude/skills/` directory holds reusable procedures. They are NOT auto-loaded; trigger them by phrase or slash command.

- **Daily update check** — `.claude/skills/daily-update-check/SKILL.md`
  Trigger phrases: `run the daily update check`, `check for dependency updates`, `bump upstream versions`.
  When you see any of these, read the SKILL.md file and follow its procedure verbatim. The file pin-table is the source of truth for what to check and where each version is written.
